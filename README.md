# NexaMind AI — Enterprise Intelligence Platform

A dark-themed AI company webpage built with HTML5 and CSS3, showcasing core AI products, industry applications, infrastructure benchmarks, leadership team profiles, and a technical demo request form.

**Live URL:** [https://vyshnavi-mamidisetti.github.io/website-of-technology/](https://vyshnavi-mamidisetti.github.io/website-of-technology/)

## Sections Included
- **Navigation Bar:** Sticky header with quick links to **Products**, **Applications**, **Technology**, **Team**, and **Contact**.
- **Hero Section:** Features the headline *"Autonomous Intelligence for Modern Enterprises"*, value proposition, and a **Request API Access** call-to-action button.
- **Core AI Products:**
  - **NexaCore LLM:** Enterprise reasoning engine with a 128K context window, deterministic JSON outputs, and zero data retention.
  - **VisionPulse SDK:** Real-time object detection and defect inspection for manufacturing lines and smart retail cameras.
  - **DocuGraph RAG:** Semantic search and citation-backed answers across internal PDFs and SQL tables.
- **Industry Applications:**
  - **Healthcare Diagnostics:** Automated radiology triage and structured clinical note summarization with HIPAA-grade encryption.
  - **FinTech Fraud Shield:** Sub-20ms anomaly detection scoring high-volume transactions to prevent payment fraud.
  - **Supply Chain Forecasting:** Predictive inventory demand modeling using weather, port congestion, and ERP data.
- **Infrastructure & Benchmarks:** Highlights `18 ms` average first-token latency, `99.99%` enterprise SLA uptime, `SOC2 Type II` encrypted inference, and `On-Prem / Cloud` (`Docker` & `Kubernetes`) readiness.
- **Leadership Team:** Profiles for **Dr. Kavya Rao** (CEO & Co-Founder), **Marcus Chen** (CTO), and **Elena Rostova** (VP of AI Safety & Alignment).
- **Contact / Demo Form:** Interactive form to schedule a technical demo with name, work email, and workload details.

## Built With
- HTML5
- CSS3 (CSS Variables, Flexbox, CSS Grid, Gradients, Media Queries)

## Running Locally
1. Clone or download the repository files (`index.html` and `style.css`).
2. Open `index.html` in a browser or launch it using **Live Server** in VS Code.
